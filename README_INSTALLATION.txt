FC NE TRAININGSAPP V1.0 – iPHONE INSTALLATION

Dies ist eine installierbare PWA.
Wichtig: Die Dateien müssen über HTTPS auf einem Webserver bereitgestellt werden.
Eine lokal geöffnete HTML-Datei kann keinen Service Worker installieren.

Nach dem Hochladen:
1. URL in Safari auf dem iPhone öffnen.
2. Teilen antippen.
3. Zum Home-Bildschirm hinzufügen.
4. Falls angeboten: Als Web-App öffnen aktivieren.
5. Hinzufügen.

Danach erscheint FC NE Training mit dem gewählten App-Icon auf dem Home-Bildschirm.
Trainings/Favoriten/Verlauf bleiben weiterhin lokal im Browser/Web-App-Speicher.
